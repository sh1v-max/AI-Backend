# Topics

Notes folder for the AI backend learning path. One numbered subfolder per concept, each with a `NOTES.md` you fill in as you learn it.

- **[OVERVIEW.md](OVERVIEW.md)** — the stack used across these topics, and what each concept teaches
- **[../PROGRESS.md](../PROGRESS.md)** — the single tracker for what to do next, in order (start there)
- **[../ai-backend-roadmap.md](../ai-backend-roadmap.md)** — the full build plan these topics are drawn from

## Structure

```
topics/
├── 01-embeddings ... 13-deployment/         basic path — do these first, in order
├── 14-graphql-subscriptions ... 16-idempotency-multi-tenancy/   production web-layer gaps
└── advanced/                                deeper pass — only after 01-16 are done
    ├── 01-prompt-engineering ... 07-vendor-abstraction
```

Each folder's `NOTES.md` follows the same shape: what the concept is, key facts, and questions that felt unclear. A topic isn't done until the notes are filled in your own words — not just when the related code runs.

Don't track progress in this file — see [../PROGRESS.md](../PROGRESS.md) for that.
