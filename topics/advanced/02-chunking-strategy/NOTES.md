## Key things to learn

- Fixed-size chunking vs semantic chunking (split by paragraph/heading vs word count)
- Chunk overlap — why some overlap between chunks helps retrieval
- Tradeoff: smaller chunks = more precise retrieval but less context per chunk; larger chunks = more context but noisier matches
- How chunk size interacts with embedding model limits and LLM context window
